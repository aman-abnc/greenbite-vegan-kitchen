# GreenBite Vegan Cloud Kitchen

A 100% plant-based, cruelty-free local business website built as part of the WsCube Tech Milestone 1 Project.



# Pages Included

1. Home (`index.html`) - Introduction to the compassionate vegan mission, top announcement bar, and highlights.

2. Vegan Menu (`menu.html`) - Responsive card layout showcasing plant-based dishes, salads, and smoothies with prices.

3. Our Story (`story.html`) - The vision behind choosing a cruelty-free and sustainable lifestyle.

4. Contact Us (`contact.html`) - Accessible order and query form with proper validation.

# Technologies Used
- HTML
- Tailwind CSS
- Git & GitHub
- Vercel (Deployment)
